Standing waves on a string

Two oppositely travelling waves interfere. The fixed ends remain at nodes; each harmonic has a different number of antinodes.

Resultant standing wave Nodes

String controls

Harmonic properties

Ideal string: v = √(T/μ), λₙ = 2L/n, fₙ = nv/(2L). Here μ is mass per unit length.
